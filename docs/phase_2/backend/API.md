# API Reference — after Phase 2

Base: `/api/v1` · No trailing slashes · JSON only · Bearer auth except where noted.
Authoritative contract: [`../openapi.yaml`](../openapi.yaml) (regenerate: `cd backend && DJANGO_SETTINGS_MODULE=config.settings.dev ../myenv/bin/python manage.py spectacular --file ../docs/phase_2/openapi.yaml`).

Phase 1 endpoints (auth, profiles, subjects) are documented in [`../phase_1/backend/API.md`](../../phase_1/backend/API.md) and unchanged. This page adds the canvas API.

## Canvas conventions

- Every mutating call carries `device_id` + `lock_generation`; the server validates holder + generation + unexpired lock, else **`409 SESSION_LOCK_LOST`** (§5).
- List responses paginated (`{count,next,previous,results}`, size 50).
- Errors use the §61 envelope.

---

## POST /api/v1/canvas/sessions — authenticated

| | |
|---|---|
| Request | `{"profile": "<uuid>", "device_id": "<string≤64>", "subject": "<uuid>" (optional)}` |
| Authorization | profile must belong to caller → else `403 FORBIDDEN` |
| Success | `201` session object; creator device holds the initial lock (`lock_generation: 1`, expiry now+90 s) |
| Errors | `422` validation; `403` foreign profile |
| Side effects | creates session row with granted lock |

```json
{
  "id": "…", "profile": "…", "subject": null, "device_id": "devA",
  "lock_holder": "devA", "lock_generation": 1,
  "lock_expires_at": "2026-08-22T10:00:90Z",
  "pages": [], "created_at": "…", "updated_at": "…"
}
```

## GET /api/v1/canvas/sessions — authenticated
List own sessions, newest first. Paginated.

## GET /api/v1/canvas/sessions/{id} — authenticated
Retrieve one own session incl. `pages[]`. Foreign/unknown → `404`.

## POST /api/v1/canvas/sessions/{id}/heartbeat — authenticated

| | |
|---|---|
| Request | `{"device_id", "lock_generation"}` |
| Validation | fencing check (holder + generation + unexpired) |
| Success | `200` refreshed session (`lock_expires_at` = now+90 s) |
| Errors | `409 SESSION_LOCK_LOST` on any mismatch/expiry |
| Idempotency | none (each call extends the lease) |

## POST /api/v1/canvas/sessions/{id}/takeover — authenticated

| | |
|---|---|
| Request | `{"device_id"}` |
| Behavior | force-transfers ownership: `lock_generation += 1`, holder = caller's device, expiry reset |
| Success | `200` updated session |
| Errors | `422` missing device_id; `404` foreign/unknown session |
| Side effects | all other devices' writes now fail with 409 |

## POST /api/v1/canvas/pages — authenticated

| | |
|---|---|
| Request | `{"session": "<uuid>", "page_number": 1, "device_id", "lock_generation"}` |
| Validation | fencing check; unique `(session, page_number)` |
| Success | `201` page object |
| Errors | `409 SESSION_LOCK_LOST`; `422` duplicate page number / validation; `404` foreign session |

## POST /api/v1/canvas/pages/{id}/strokes — authenticated

| | |
|---|---|
| Request | `{"device_id", "lock_generation", "strokes": [{"id?": uuid, "sequence_order": int≥0, "points": number[] (len ≥2), "client_idempotency_key": string≤64}]}` |
| Validation | fencing check; per-stroke field checks; page not finalized |
| Success | `200 {"created": ["<stroke-id>"], "duplicate_keys": ["<key>"]}` — batch may mix both |
| Idempotency | **replay-safe**: a repeated `client_idempotency_key` never creates a second row (unique constraint + savepoint create) |
| Errors | `409 SESSION_LOCK_LOST` (fencing); `409 REVISION_CONFLICT` (page finalized); `422` validation; `404` foreign/unknown page |
| Side effects | inserts new stroke rows only |

Example replay:

```json
{ "created": ["79fbf8ed-…"], "duplicate_keys": ["k1"] }
```

## POST /api/v1/canvas/pages/{id}/finalize — authenticated

| | |
|---|---|
| Request | `{"device_id", "lock_generation"}` |
| Behavior | single transaction: fencing check + mark page finalized (§67). Idempotent. |
| Success | `200 {"page_id","is_finalized":true,"already_finalized":bool}` |
| Errors | `409 SESSION_LOCK_LOST`; `404` foreign/unknown page |
| Downstream | ⚠️ document revision creation + OCR job enqueue arrive in Phase 3 within this same transaction |
