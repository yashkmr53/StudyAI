# Troubleshooting — after Phase 7

Prior guides: [`../phase_6/operations/TROUBLESHOOTING.md`](../operations/TROUBLESHOOTING.md) and earlier. New entries:

## POST /tests returns 201 with zero questions

No eligible questions exist: they are generated by the enrich tail (or refresh-ai). Run enrich/refresh first and confirm `questions_question` has non-stale rows for the document's profile/subject.

## Attempt returns 409 IDEMPOTENCY_CONFLICT

The question was already answered in this test instance. One attempt per question per test — create a new test for another round.

## mastery is null on an attempt

The source document had no subject at enrichment time, so no tag link exists. Assign the document to a subject, then refresh-ai to regenerate questions with tags; new attempts will update mastery.

## Chat answers "I could not find anything…"

Retrieval found no matching chunks: confirm the document was indexed (`retrieval_notechunk` rows with `stale=false`), that tokens appear in content (hashing embeddings are lexical), and that any referenced book is READY.

## Tags missing for a document

Documents need a subject before tagging works (§18). Assign a subject, then refresh-ai.

## Planner shows empty focus lists

Fewer candidate tags than sessions, or none linked to the profile. Enrich/index documents so tags exist.
